Open the live app → Source on GitHub llms.txt

What it is

A case & format converter for developers and writers. Type, paste, or drop text into one box and see it rendered in 16 cases at once — copy any with one click. Runs entirely in your browser.

Key features

  • 16 case transforms: camelCase, PascalCase, snake_case, CONSTANT_CASE, kebab-case, COBOL-CASE, dot.case, path/case, space case, Title Case, Sentence case, lowercase, UPPERCASE, Capitalize Words, StUdLyCaPs, iNVERSE cASE.
  • Per-line or whole-block conversion for lists of identifiers.
  • Drag-drop or pick a text file (.txt .md .csv .json .js .ts .py).
  • Slug + social-handle generators (diacritics stripped).
  • Optional AI: suggest a variable/function name from a description, or turn prose into a URL slug.

Tech

  • Client-only Astro (static) + React 19 islands.
  • g4f AI via @chirag127/oz-ai — multi-provider failover, no API key.
  • PWA-installable.
  • 100% in-browser — no upload, no signup, no tracking. The only network call is the optional AI feature, triggered explicitly.
